# 🛒 BazarDor (বাজার দর)
**BazarDor** is a modern, user-friendly web application designed to bring greater transparency and reliable insights into the prices of everyday essentials across Bangladesh.

Through this platform, users can easily compare the prices of the same products across different regions and local markets throughout the country. By tracking price fluctuations over time, they can identify where and when to shop to get the best value for their money.
BazarDor is more than just a platform for checking product prices. It is a practical tool that empowers consumers to make informed purchasing decisions, reduce unnecessary expenses, plan their budgets effectively, and make the most of their hard-earned money.
The application allows users to explore daily prices of essential commodities, monitor market price trends, create personal accounts, and manage their profiles through a smooth and intuitive user experience.

## ✨ Key Features

* **📊 Daily Price Tracking (Market Prices):**
    * Easily explore updated daily prices of essential commodities, including vegetables, rice, fish, and meat.
    * Browse organized product categories with clear pricing and unit-based details (kg, litre, piece, etc.).

* **📈 Price Fluctuation & Trend Analysis:**
    * Track daily price changes by comparing current prices with previous prices, including percentage increases and decreases.
    * Understand market trends at a glance through intuitive visual indicators, helping users identify price movements and potential savings opportunities.
    * Compare the prices of the same products across different regions and local markets in Bangladesh to make smarter purchasing decisions.

* **🔒 Secure Authentication System:**
    * Secure user registration and login using email and password authentication.
    * **Social Login:** Convenient, one-click sign-in using Google and GitHub accounts.

* **👤 Personalized Profile & Account Management:**
    * A dedicated user profile dashboard where users can update their names and manage personal information.
    * A personalized experience designed to make account management simple and convenient.

* **📱 Modern & Responsive User Interface:**
    * A clean, intuitive, and responsive interface built with Tailwind CSS and HeroUI.
    * Skeleton loading states for a smoother perceived loading experience while content is being fetched.
    * Optimized layouts for mobile, tablet, and desktop devices, ensuring a consistent user experience across screen sizes.

* **💰 Smarter Shopping & Cost Savings:**
    * Make informed purchasing decisions using market price information and price comparisons.
    * Identify potential savings, reduce unnecessary expenses, and plan household budgets more effectively.


## 🛠️ Technologies Used

- **Framework:** Next.js (App Router)
- **Library:** React.js
- **Styling:** Tailwind CSS
- **UI Components:** HeroUI (formerly NextUI)
- **Notifications:** React Toastify
- **Authentication:** Custom Auth Client (Email/Password, Google, GitHub)
